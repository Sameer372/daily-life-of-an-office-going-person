# Daily Life of an Office-Going Person

## Overview

An interactive computer graphics project developed using C++ and OpenGL. It illustrates the daily routine of an office-going person through animated visual scenes, including a neighborhood, a rainy city environment, and an office setting.

## Scenes

- **Neighborhood:** Visual representation of a residential neighborhood.
- **Rainy City:** An animated city environment featuring rainy weather.
- **Office:** A visual representation of an office environment.

## Technologies Used

- C++
- OpenGL
- GLUT
- Code::Blocks

## Project Files

- `main.cpp` – Main C++ source code.
- `Graphics Project.cbp` – Code::Blocks project configuration file.

## How to Run

1. Open `Graphics Project.cbp` in Code::Blocks.
2. Ensure the required OpenGL and GLUT libraries are configured.
3. Build and run the project.

## Project Purpose

The project demonstrates the use of computer graphics and animation to represent everyday life through interactive visual scenes.
